# Production deployment architecture

SecureSight runs as one non-root Gunicorn container on a single host. The host's TLS reverse proxy is responsible for HTTPS, request-size/time limits, and forwarding only trusted client-IP headers. The Compose port binds to loopback so the application is not exposed directly to the Internet. Keep the reverse proxy and host firewall configured accordingly.

Build the image in CI, publish it to a private or otherwise controlled registry, and deploy an immutable `sha256` image digest. Do not mount the source checkout, datasets, model directories, or `.env` into production. Compose persists only `/var/lib/securesight`, which holds encrypted SQLite dashboard state. The host volume and backups still need restrictive access controls.

The production service requires an independently managed Redis service reachable over a private network, preferably TLS with a scoped credential. It is used for shared rate-limit state and email-job coordination. Redis is not included in this Compose project. The service is deliberately one Gunicorn worker because the application currently uses a single-host SQLite dashboard store; scale-out requires a reviewed database migration and shared job deployment.

Production deployment is blocked until operators provide real HTTPS origins and trusted hostnames, high-entropy independent Flask and dashboard keys, Redis, encrypted backup storage, and an incident/retention owner. Keep `SEO_INDEXING_ENABLED=false` until the public canonical domain and release checks are approved. The repository's Render descriptor uses a free service and does not provide durable dashboard storage; treat it as an ephemeral staging target with dashboard persistence disabled, or select and configure a durable production data service before public deployment. This change does not deploy or publish the application.

The Compose bridge still allows outbound network access. Application URL-fetch/SSRF checks remain enabled, but Docker networking alone is not an egress boundary. Before processing untrusted URLs publicly, enforce and verify the deployment host's egress firewall or controlled egress proxy against the existing destination policy. No proxy/ingress configuration, firewall rules, DNS, or TLS certificates are included here. Media analysis scratch files are temporary; persistent private investigation records use the dashboard database volume.
