# Synthetic media

Synthetic, manipulated and facially manipulated probabilities remain independent nullable fields. Unknown is not zero probability and is not SAFE. There is no evaluated CNN/ViT/frequency ensemble available, so model agreement and calibrated confidence are unavailable.

Quality reports minimum dimension and measured edge gradient; images under 64 pixels on an edge or almost uniform are INSUFFICIENT_QUALITY. These provisional quality flags reduce interpretability, never add phishing risk, and do not represent model accuracy. Crop, occlusion, face size and semantic lighting confidence require evaluated detectors and are not inferred here.
