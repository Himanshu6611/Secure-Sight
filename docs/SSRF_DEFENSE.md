# Outbound and SSRF defenses

HTTP entry points: static web/robots/crawl fetches in `utils/safe_fetch.py`, HTTPS JSON/RDAP providers in `app/security/json_fetch.py`, HEAD compatibility in `app/security/outbound.py`. Each uses shared `pinned_pool`, `validate_url`, `resolve_public` and `public_ip`. No requests client/env proxy/browser bypass exists in active scanning. External reputation skeletons return unavailable; dynamic browser execution remains disabled.

Only HTTP/HTTPS and ports 80/443 are accepted. URL credentials, controls, parser ambiguities, special/private/reserved/link-local/metadata/multicast/non-global addresses, IPv6 mapped/tunnel/NAT64 ranges and unusual numeric IPv4 forms are blocked. Every DNS A/AAAA answer must be public. Connect to a validated literal while preserving the original TLS server/assert hostname; there is no second hostname resolution at socket creation. Mixed public/private answers fail closed. Every redirect is validated again and resolves through a new pinned pool. Tests cover private provider redirects, rebinding to a private answer, TLS pinning and prohibited IP forms.

Redirect, connect/read/total deadline and response byte budgets are enforced. Compressed HTTP bodies are rejected and read with decode_content=False. No incoming cookies, bearer credentials, internal headers or cloud credentials are forwarded; requests use a fixed allowlisted header set. HTTPS JSON has one redirect and 128 KiB maximum; strict JSON checks reject duplicate/non-finite/deep responses. Its bounded process-local origin circuit opens after three failures for 30 seconds with one recovery probe, maximum 128 entries. It is not a distributed breaker and does not suppress hostile website fetches globally.

TLS observation uses the same URL/public-IP policy and verified literal sockets. WHOIS (port 43, not HTTP) validates its domain, IANA/registry referral and public literals with a total deadline/64 KiB limit. DNS/DKIM/DMARC queries use bounded resolver lifetimes; they do not fetch links from message headers. MIME/OCR/QR destinations enter the same existing URL scanner; no attachment-supplied destination bypasses validation.

Application SSRF defenses do not replace deployment network isolation. Decoder processes have the parent account's network permissions. A real browser/container worker with restricted egress is not implemented or claimed.
