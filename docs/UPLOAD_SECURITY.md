# Upload and worker security

Global request cap: 6 MiB; form memory 128 KiB, ten parts. Media intake cap: 5 MiB, allowlisted PNG/JPEG/WebP magic/MIME; supplied filename extension must match its format. Paths in filenames are never used for storage. API filenames are discarded; HTML uses secure_filename for display only. SVG/HTML/executable/animated/polyglot/trailing invalid formats are rejected. Decoder verifies original format, single frame, maximum dimension 4096 and eight million pixels; errors never mean safe.

Email is at most 2 MiB, 20000 lines; bounded headers, MIME depth eight/32 parts, decoded body 64 KiB, eight attachments of at most 512 KiB each/1 MiB aggregate. ZIP central metadata is inspected without filesystem extraction: 64 entries, 1 MiB/member, 2 MiB expanded aggregate, ratio at most 100. Nested/encrypted archives and unsafe paths remain partial/uninspected. Executables/macros are flagged and never executed. No uploaded file is stored in static/executable web roots.

Decoder children use fixed interpreter/module/allowlisted args and stdin bytes; no shell. Each job gets a new TemporaryDirectory as cwd/TEMP/TMP/TMPDIR, cleaned after success, failure, start failure or timeout. Trusted module search is pinned to the repository. Only required OS/PATH/OCR/C2PA environment entries survive; service session/dashboard/Redis/cloud/proxy credentials do not. Linked URL scanner children use an isolated testing-mode Flask context solely for analysis, same Phase 6/7/model/config files, no dotenv or dashboard persistence. Testing-mode memory services here do not weaken outbound SSRF or risk policy.

Wall deadline 15 seconds (linked URL 25), CPU ten seconds, job memory 1 GiB, bounded stdout and killed descendants. Windows Job Objects and Unix rlimits/process groups enforce these process budgets; Unix/container operation was not exercised on this Windows host. Temporary storage separation and resource limits are not an OS security sandbox: children retain parent filesystem/network permissions, and assignment occurs after process launch. Dynamic browser isolation is unavailable and cannot be enabled. Hardened container/seccomp/AppArmor/egress policy remains a public deployment gate.
